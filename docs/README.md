# SmartToll documentation

Technical documents for the SmartToll capstone project (Holy Angel University). The diagrams are written in Mermaid, which GitHub draws directly when you open these files there.

| Document | Contents |
|---|---|
| [ARCHITECTURE.md](ARCHITECTURE.md) | System overview, how a toll is computed, saving a trip and the RFID deduction, GPS trip tracking, deployment, security measures |
| [DATABASE.md](DATABASE.md) | Entity-relationship diagram (ERD) and every table and column, generated from the live schema |
| [API.md](API.md) | Every REST endpoint (public, motorist, administrator), generated from the route list |
| [TESTING.md](TESTING.md) | Automated test results (45 tests) and the end-to-end checks |

For installing and running SmartToll, see the main [README](../README.md).
